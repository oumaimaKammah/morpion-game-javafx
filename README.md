# 🎮 Morpion Game JavaFX (Tic-Tac-Toe)

## 📝 Overview
A Tic-Tac-Toe game built with JavaFX, designed with clean architecture principles (SOLID) and a modern pastel UI theme.  
The project demonstrates strong Object-Oriented Programming (OOP) through clear class separation, encapsulated game logic, and a modular, maintainable structure.  
The game board is managed by **GameBoard**, the win logic is handled by **GameLogic**, and the user interface is implemented in **GameView**.  
It also includes JUnit 5 unit tests, full JavaDoc documentation, and a GitHub Pages deployment for easy access.

## 🚀 How to Run the Project

### Requirements
- Java 17 or higher  
- Maven  

### Commands
```bash
mvn clean install
mvn javafx:run
```

---

## 🧪 Running Tests
Unit tests are written with **JUnit 5** and cover the core game logic.

```bash
mvn test
```
